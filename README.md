# Backuppo

Tool di backup open source, cross-platform, distribuito come singolo binario statico
(comando `bkpo`). Configurabile via YAML versionabile su git, con notifiche
SMTP/Telegram e verifica automatica del restore come differenziatore principale
rispetto ai tool esistenti.

Vedi [`roadmap.md`](roadmap.md) per lo stato di avanzamento e le decisioni di progetto.
