# Backuppo v0.1.0

Prima release stabile dell'agent di backup Backuppo.

Include backup cifrati verso filesystem, SFTP, S3 e WebDAV; sorgenti file,
database e Docker; verifica automatica del restore; scheduler con retention;
notifiche; report; storico SQLite e pagina di stato.

Consulta `docs/quickstart.md` nell'archivio della tua piattaforma. Verifica il
download con il file `SHA256SUMS` allegato alla release.
