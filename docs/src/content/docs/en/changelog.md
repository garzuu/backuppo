The detailed change history lives in
[`CHANGELOG.md`](https://github.com/garzuu/backuppo/blob/main/CHANGELOG.md)
in the repository, updated with every release. This page summarizes the
project's direction: what's already available and what's still to do,
without promising dates.

## Available today

- Stand-alone agent with automatic restore verification, optional Restic
  engine, `age` encryption, local/SFTP/S3/WebDAV/cloud drive destinations.
- Optional multi-site hub, limited remote commands, signed security
  policies.
- Embedded web UI (multi-job wizard, history, selective restore), PWA,
  optional Tauri desktop wrapper.
- Signed binaries for Linux/macOS/Windows, Docker image on GHCR, automatic
  `.deb`/`.rpm` packages on every release. Templates for Homebrew, AUR and
  winget are ready (manual publication step, see
  [system packages](../packaging/)).
- Restic append-only mode, S3 Object Lock verification, Ed25519-signed
  updates with rollback.

## In progress or planned

No timeline commitment: the order reflects current priorities, not a
guaranteed sequence.

- **Publishing external packages**: open PRs against a personal Homebrew
  tap, AUR and `winget-pkgs` for upcoming releases (the files are already
  generated by the rendering script; only the publication step is
  missing).
- **Additional VM sources**: today only libvirt/KVM is supported (VM
  powered off). VMware (vSphere/ESXi) and Proxmox (PVE) are candidates but
  not implemented yet.
- **Interactive assisted restore**: a guided flow (interactive `bkpo
  restore`, job/date/destination selection, restoring a database directly
  into a container) beyond what's already available via CLI/API/UI.
- **Integrations**: a Prometheus metrics endpoint, Home Assistant
  integration, a read-only MCP server to query backup status.
- **Website**: comparison table ([already published](../confronto/)) and
  automated broken-link checking in CI are already live.

## Reporting an issue or proposing something

Issues and discussions live on
[GitHub](https://github.com/garzuu/backuppo). For non-trivial changes,
open an issue first: see
[CONTRIBUTING.md](https://github.com/garzuu/backuppo/blob/main/CONTRIBUTING.md)
for project conventions. For security vulnerabilities, follow
[SECURITY.md](https://github.com/garzuu/backuppo/blob/main/SECURITY.md)
instead and don't open a public issue.
