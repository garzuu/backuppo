## Cos'è Backuppo

Backuppo è un sistema di backup self-hosted per Linux, Windows, macOS e
Docker. Ogni Agent può lavorare da solo oppure inviare esclusivamente stato e
metadati a un Hub centrale.

<CardGrid stagger>
	<Card title="Verifica automatica del restore" icon="approve-check">
		Un backup si considera riuscito solo dopo che l'upload è confermato e,
		se attivo, il restore è stato verificato: numero di file, dimensioni,
		checksum di un campione, query di sanità per i database.
	</Card>
	<Card title="Singolo binario statico" icon="rocket">
		Nessuna dipendenza da installare a parte. Build statiche per Linux
		(musl), Windows e macOS, oltre a un'immagine Docker minimale.
	</Card>
	<Card title="Sorgenti e destinazioni" icon="setting">
		Cartelle, PostgreSQL, MySQL/MariaDB, SQLite, volumi Docker, comandi
		custom. Locale, SFTP, S3-compatibili, WebDAV, Google Drive, Dropbox,
		OneDrive.
	</Card>
	<Card title="Hub multi-sito opzionale" icon="open-book">
		L'agent funziona sempre stand-alone. Un hub opzionale raccoglie stato e
		metadati da più siti, rileva quelli offline e consente operazioni remote
		strettamente controllate.
	</Card>
</CardGrid>

## Scegli il tuo percorso

- **Una sola macchina:** installa l’[Agent](./installazione/), configura uno o
  più job con il [wizard](./wizard-job/) e resta in modalità stand-alone.
- **Più sedi o clienti:** installa un Agent in ogni sito, poi distribuisci un
  [Hub](./hub/) centrale. I backup non passano mai dall’Hub.
- **Devi recuperare dati:** vai direttamente alla guida al [restore](./restore/).
